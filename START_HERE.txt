ON THE OTHER LAPTOP
The other laptop needs Ubuntu 24.04 x86_64, ROS 2 Jazzy, and the official V1.1
simulator already installed. Windows alone is insufficient for these scripts.
Extract the ZIP. Open a terminal in this folder.
Replace /path/to/competition-repo in every command with the real simulator folder.

1. BUILD
bash build.sh /path/to/competition-repo

2. START SIMULATOR in another terminal, from the competition repository:
./scripts/launch_sim.sh
Stop any PS5/manual teleoperation or other driving controller.

3. VERIFY CONNECTIONS (keeps speed at zero for approximately 12 seconds)
bash verify.sh /path/to/competition-repo
Expected: PASS. If it fails, copy the complete terminal output for troubleshooting.

4. DRIVE SLOWLY
bash run.sh /path/to/competition-repo 0.4
Watch RViz. First finish-line crossing starts the timer; the NEXT completes lap 1.
Verify THREE TIMED LAPS and ZERO COLLISIONS. Ctrl+C stops the controller.
If a drive command remains active, from the official repository run:
./scripts/stop_car.sh

5. OPTIONAL BASELINE SPEED (only after a successful low-speed test)
bash run.sh /path/to/competition-repo 0.8
Respect any lower speed cap announced by the organizers. The official cap is not
specified in the linked documentation. No lap-time threshold is stated for Stage 1.
Do not change code or settings during an official attempt.

PACKAGE NAME: team_controller
DECLARED DEFAULT COMMAND: ros2 run team_controller controller
DEFAULT MAXIMUM REQUESTED SPEED: 0.8 m/s
LOW-SPEED COMMAND: ros2 run team_controller controller --ros-args -p max_speed:=0.4
